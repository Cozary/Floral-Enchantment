# Floral Enchantment

Looking for a simple mod to decorate? This mod adds flower bushes with which you can obtain the vines of each flower.
Also like mossy cobblestone, you can get mossy cobblestone from each flower to decorate! As well as mossy stone bricks.
It also includes pots and long pots to place the flowers. As well as floral baskets and flower crowns.

## Translations

If you would like to help translate Floral Enchantment into your language:

1. Use the English reference file: [`en_us.json`](common/src/main/resources/assets/floralench/lang/en_us.json).
2. Create or update your language file (e.g., `de_de.json`, `fr_fr.json`) inside [`common/src/main/resources/assets/floralench/lang/`](common/src/main/resources/assets/floralench/lang/).
3. Submit your translation by opening a [Pull Request](https://github.com/Cozary/floral-enchantment/pulls) (or open an issue with the translated file/entries).

Any translation contributions are always appreciated!
