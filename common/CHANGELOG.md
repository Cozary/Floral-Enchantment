# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [NeoForge 1.3.0 | Fabric 1.4.0 | Forge 1.7.0] - 2026-10-30

- Ported to Minecraft 26.3.

### Added
- Floral vines can now be sheared with shears to stop them from spreading.

### Fixed
- Fixed being unable to place flowers in Large Pots on Fabric (#10).
- Fixed Large Pot holding animation in third person.
- Fixed Large Pot model display and centering in third person.
- Fixed Large Pot model display in first person.

## [NeoForge 1.2.0 | Fabric 1.3.0 | Forge 1.6.0] - 2026-08-24

### Changed
- Ported to Minecraft 26.2.

## [NeoForge 1.2.0 | Fabric 1.3.0 | Forge 1.6.0] - 2026-08-22

### Added
- Added Golden Dandelion variant blocks and items:
  - Golden Dandelion Vine
  - Golden Dandelion Mossy Cobblestone
  - Golden Dandelion Mossy Stone Brick
  - Golden Dandelion Vine Bush
  - Large Golden Dandelion Pot
  - Large Double Golden Dandelion Pot
  - Golden Dandelion Floral Basket
- Added recipes, tags, blockstates, models, and loot tables for Golden Dandelion variants.
- Added English (`en_us`) and Spanish (`es_es`) localizations for Golden Dandelion variants.
